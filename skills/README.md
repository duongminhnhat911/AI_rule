# Skills Directory (Gói Kỹ Năng Mở Rộng)

Thư mục này dùng để lưu trữ các **Skill Packs** chuyên sâu (dạng thư mục chứa `SKILL.md`, tài liệu tham chiếu, bảng dữ liệu hoặc script hỗ trợ) nhằm mở rộng năng lực cho AI Coding Agent theo từng chuyên ngành.

## Cấu Trúc Gợi Ý Cho Một Skill Mới
```text
skills/
└── <ten-skill>/
    ├── SKILL.md          # Chỉ thị chính cho AI về cách kích hoạt và thực thi skill
    ├── references/       # Tài liệu, bảng chuẩn, ví dụ mẫu
    └── scripts/          # Các script tự động hóa đi kèm (tùy chọn)
```

## Cách Bổ Sung Skill Cộng Đồng
Bạn có thể clone hoặc đặt các skill mở rộng (ví dụ: `ui-ux-pro-max-skill`, `database-architect`, `devops-k8s`, `security-audit`) vào đây để hệ thống tự động nhận diện.
